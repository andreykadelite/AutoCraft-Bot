Краткая инструкция

  1. Откройте вкладку Клавиатура или Мышь.
  2. Выберите готовую команду и нажмите Отправить, либо соберите свою в конструкторе ниже.
  3. Текстовые команды создаются во вкладке Свои пресеты, в блоке Текстовый пресет.
  4. Чтобы использовать команду повторно, нажмите Сохранить в пресеты.
  5. Вкладка Свои пресеты: запуск, редактирование и удаление ваших команд.
  6. Вкладка История: повтор недавно отправленных команд и очистка журнала.

Навигация с клавиатуры

  • Вкладки переключаются мышью или клавишами Left/Right/Home/End.
  • Кнопки и поля доступны через Tab.
  • Ctrl+Enter отправляет команду в активной вкладке (Клавиатура, Мышь, Свои пресеты).
  • Информация о результате озвучивается через статус-блок над вкладками.
