Win TTS

Синтез речи с выбором движка и голоса. Результат можно сразу прослушать в браузере и скачать.

Расширение

RHVoice-addon

Установка создаёт локальное addon-окружение в data/addon_win_ttts. Ниже доступен подробный лог установки и ошибок сети.

Лог установки RHVoice-addon Установка еще не запускалась. 
Лог установки появится после запуска.

Настройка первого голоса

Если язык доступен для выбранного движка, сначала выберите язык, затем голос.

Для Edge TTS можно выбрать безопасный уровень параллельной обработки частей текста.

Сколько раз повторять gTTS-часть при временной ошибке сети или сервиса.

Значения применяются по возможностям выбранного движка. 0 = нейтрально.

Настройка второго голоса

Если настройка второго голоса скрыта, выбранный движок не поддерживает этот режим.

Укажите язык и голос для фрагментов на другом алфавите.

Настройки применяются только к второму голосу.

Авто-режим уменьшает лишние паузы на стыках кириллицы/латиницы. В ручном режиме задается фиксированная пауза.

Введите любые служебные символы подряд. Например: #@$%^&.

Нормализатор применяется перед синтезом для всех движков и помогает убрать служебные символы, которые могут озвучиваться как «звездочка», «решетка» и т.д.

Анализатор нормализатора текста

Вставьте текст или импортируйте файл, чтобы посмотреть, как нормализация влияет на озвучку.

    Подсказки
    
      
      
        
    • В текущей реализации для длинных текстов и книг оптимален Edge TTS: он наиболее стабильно обрабатывает большие объёмы благодаря автоматической сегментации и склейке аудио.
      • 
        
    • Нормализатор и анализатор доступны для всех движков: они удаляют служебные символы и разметку, чтобы синтез не проговаривал «звездочка», «решетка» и похожие маркеры.
      • 
        
    • Можно загружать TXT, FB2, EPUB, DOCX, MD и HTML прямо из браузера. После импорта текст остаётся доступен для правки.
      • 
        
    • Параметры скорости, тона и громкости отображаются единообразно. Для Google TTS доступен язык и базовая скорость, для pyttsx3 — скорость и громкость.
      • 
        
    • Google TTS и Edge TTS формируют MP3, pyttsx3 и RHVoice формируют WAV.
      • 
        
    • История хранит только безопасный фрагмент больших текстов, поэтому для повторной озвучки крупных книг лучше повторно импортировать исходный файл.
      • 
        
    • Сгенерированные файлы доступны для скачивания напрямую из браузера.
