
# Changelog

## 1 июня 2025
- Команда `hrp` теперь доступна только авторизованным пользователям (security fix).
- Авторизация по PIN-коду приведена к единому стандарту:
  - После успешной авторизации отправляется сообщение «Вы авторизовались».
  - Выводятся накопленные логи (если они есть).
  - Показывается статус режима дебага.
- Версия приложения для устройств теперь берётся из `info.py` — исключено дублирование, упрощена разработка.
- Реализовано автоматическое восстановление работы приложения при аварийном закрытии.
- Улучшен механизм перезапуска: теперь он стабильно работает на всех версиях Windows.
- Обнаружение камер стало надёжнее: теперь камеры корректно определяются на большем количестве компьютеров, в том числе с нестандартной конфигурацией.
- Общий рефакторинг кода: поведение авторизации стало стабильным и предсказуемым, повышена читаемость и удобство поддержки.

## 4 июня 2025
- Добавлена поддержка работы с локальным сервером Telegram Bot API: теперь бот корректно взаимодействует с локальной инстанцией API, включая обработку запросов, получение файлов и другие операции.
- Если используется локальный Telegram Bot API, размер передаваемых и получаемых файлов увеличивается до 2 ГБ.
- Если используется стандартный Telegram API, лимит остаётся 20 МБ.
- Для видео с камер: при стандартном API — максимум 49 МБ, превышающее видео автоматически разделяется.
- При использовании локального API видео до 2 ГБ обрабатывается напрямую.
- При установке или скачивании плагинов временные папки `temp_plugins` и `temp_plugin_zips` удаляются автоматически.
- Папка плагина переименовывается в имя json-файла, входящего в его состав.
- Улучшена логика голосовых и медиа: файлы сохраняются корректно, учитывая используемый API.
- Исправлен переход в меню при отмене выбора голосового движка или камеры.
- Режим установки плагинов теперь работает как изолированный: обрабатываются только нужные файлы, остальные игнорируются.
- Файл логов теперь сохраняется в папку `log` рядом с `.exe` даже после компиляции с Nuitka.
- `watchdog` пишет логи только при включённом дебаг-режиме.
- После восстановления из резервной копии происходит полный перезапуск приложения.
- Улучшено логирование и отладка.
- Мелкие доработки и оптимизации.

## 8 июня 2025
- Добавлен встроенный локальный Telegram Bot API сервер: теперь дистрибутив содержит уже скомпилированную версию `telegram-bot-api.exe`, которая автоматически распаковывается в папку `serverapibot` при первом запуске.
- Настройка локального API сервера упрощена: пользователю необходимо только указать `api_id` и `api_hash`, после чего нажать кнопку запуска — сервер стартует автоматически.
- В интерфейс добавлена галочка для выбора типа API: если активна — используется стандартный Telegram API, если отключена — задействуется встроенный локальный сервер.
- Режим работы с локальным сервером поддерживает отправку и приём файлов до 2 ГБ, включая голосовые сообщения, видео и документы.

## 17 июня 2025
- Реализовано автоматическое удаление временных директорий `temp_plugins` и `temp_plugin_zips` после установки и скачивания плагинов.
- `watchdog` логирует только при активном дебаге, при выключенном — не пишет логи.
- После восстановления из резервной копии выполнен корректный перезапуск, аналогично кнопке "Полный перезапуск".
- Папка плагина автоматически переименовывается в имя json-файла, об этом сообщается в Telegram.
- Логирование адаптировано под exe: все логи (`bot`, `tools`, `watchdog`) сохраняются в `log` рядом с файлом.
- Исправлен возврат в меню при отмене выбора голосового движка и камер.
- Добавлены проверки: файлы и голосовые обрабатываются только в нужных режимах, в остальных — игнорируются.
- Обновлены модули логирования, камер, голосового и плагин-системы.
- Мелкие исправления и улучшения стабильности.

## 20 июля 2025
- Добавлена поддержка записи с экрана.
- Добавлена поддержка записи с микрофона.
- Проведена общая оптимизация кода и производительности.
- Файл `Python.zip` теперь встроен в `.exe`: он автоматически извлекается при необходимости, обеспечивая корректную работу встроенного интерпретатора Python.

Новые изменения за 1 октября 2025 (версия AutoCraft-Bot 1.1.6):

•

Добавлен интерактивный чат: запуск и завершение из Telegram, диалоги ведутся в отдельном режиме без влияния на остальные функции.

•

Появилась команда отправки сообщения на компьютер в виде всплывающего окна — удобно для быстрых уведомлений и напоминаний.

•

Улучшен азапись видео с экрана: запись экрана в файл (); управление старт/стоп из Telegram.

•

Реализовано управление браузером и установка браузеров (режим beta): базовые операции уже доступны; возможны баги и нестабильное поведение модуля.

•

В главное меню добавлен PowerShell: быстрый запуск консоли; команды выполняются в отдельном процессе, вывод доступен в логах и в Telegram.

•

Добавлен автозапуск программы с выбором способа:

• через Папку автозагрузки;

• через Реестр (Run).

Оба варианта корректно настраиваются и отключаются из интерфейса.

•

Для локального сервера Telegram Bot API реализован автопоиск путей к серверу: если пути в config невалидны или пустые, корректные значения подставляются автоматически.

•

Раздел «Заметки» обновлён: теперь можно читать сохранённые заметки прямо из меню.

•

Общие улучшения:

• повышена стабильность работы модулей;

• доработаны сообщения об ошибках и отладочные логи;

• выполнены мелкие оптимизации и исправления багов.
