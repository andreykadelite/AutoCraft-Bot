AutoCraft Bot — это гибридная Telegram/десктоп-утилита на Python (aiogram + PyQt5)
._Автоматизация без границ, приложение находится в разработке — возможны баги и недочёты._

## Новые изменения за **1 октября 2025** (версия **AutoCraft‑Bot 1.1.6**)
• **Интерактивный чат** — отдельный режим общения с человеком который за компьютером прямо из Telegram.
• **Всплывающие окна на ПК** — отправляйте сообщения, которые появляются как системные уведомления/окна.
• **Управление браузером** и **установка браузеров** — режим **beta**, возможны баги.
• **Автозапуск программы** — выбор способа: **Папка автозагрузки** или **Реестр (Run)**, включение/отключение из интерфейса.
• **Локальный Telegram Bot API** — **автопоиск путей** к серверу при невалидных значениях в `config`.
• **Заметки** — теперь можно **читать** сохранённые записи из меню.
• **Оптимизации и фиксы** — стабильность модулей, улучшенные логи и сообщения об ошибках.
• **Запись видео с экрана** — запись экрана в файл (при ), старт/стоп из Telegram.
• **PowerShell в главном меню** — быстрый запуск консоли; команды выполняются в отдельном процессе, вывод доступен в логах/Telegram.

## Установка и запуск
1. **Скачайте дистрибутив** в виде EXE-файла или ZIP-архива.
если в exe, то запустите программу.
если архив проекта, то точка входа bot-ok.py

2. **Обязательно** поместите рядом с bot-ok.py (в корне проекта) или рядом с  EXE-файлом архив `Python.zip`. При первом запуске он автоматически распакуется в папку `python`.
3. Запустите EXE — откроется окно настройки.

## Настройка
1. Введите **token** вашего Telegram-бота.
2. (По желанию) Задайте **PIN-код** для дополнительной защиты.
3. Укажите **ID пользователей**, которым будет разрешён доступ (через запятую).
4. Нажмите **Сохранить и подключить** — бот запустится автоматически.

## Работа с графическим интерфейсом

Графический интерфейс предоставляет удобное средство для настройки и управления ботом без необходимости редактировать файлы вручную.

### Основные поля ввода:
- **Token** — токен Telegram-бота (обязателен для запуска).
- **PIN-код** — дополнительная защита авторизации (опционально).
- **ID аккаунтов** — список ID, которым разрешён доступ к боту (через запятую, только цифры).
- **Адрес API** — URL/адрес локального Telegram Bot API сервера.
- **Порт API** — порт, по которому будет происходить подключение к серверу.

### Функциональные кнопки:
- **Сохранить и подключить** — проверяет корректность введённых данных, показывает имя бота, сохраняет настройки и запускает его.
- **Перезапустить бота** — завершает текущую сессию и перезапускает процесс.
- **Сброс** — полностью очищает настройки, обнуляет файл конфигурации и останавливает бота.
- **Справка** — открывает справочное окно с информацией.
- **Выход** — закрывает окно и завершает работу приложения.
- **Настройка локального API ** —Настраивает встроенный telegram-bot-api 
- **Свернуть в трей** — убирает окно в системный трей, возвращается по двойному щелчку.

### Логи:
- В правой нижней части окна доступна панель отображения логов в реальном времени.
- Допольнительные Логи отображаются только если включён режим отладки.

### Системный трей:
- При сворачивании бот может работать в фоновом режиме.
- Иконка в трее позволяет развернуть или закрыть приложение.

Все элементы интерфейса адаптированы под тёмную тему и имеют улучшенную доступность с описаниями для экранных читалок.

## Команды Telegram-бота
После авторизации бот выдаёт главное меню:
```
Статус сервера | Статус сети | Скриншот | Список плагинов  
Дополнительно | cmd | PowerShell | утилиты | консоль python
```
- **Статус сервера** – информация об ОС, загрузке CPU/RAM/Disk и времени работы.
- **Статус сети** – внутренний/внешний IP, интерфейсы, тест скорости.
- **Скриншот** – делает и отправляет снимок экрана; хранит только 500 последних.
- **Список плагинов** – показывает установленные расширения.
- **cmd** – быстрый доступ к системным командам (ping, ipconfig/ifconfig, dir/ls и др.).
- **утилиты** – раздел в разработке.
- **консоль python** – безопасная REPL-среда для запуска скриптов прямо в чате.

---

## Меню «Дополнительно»
```
Заметки | Отправить файлы | Прием файлов | Питание  
Плагины | Справка | лог | Настройки | Особые функции | Назад
```
- **Заметки** – вводите текст, жмите «Сохранить заметку» → файл окажется в `notes/`.
- **Отправить файлы** – включается режим: любые файлы до 20 МБ сохраняются в `files/`.
- **Прием файлов** – бот вышлет содержимое `infiles/`; «Завершить приём» вернёт в меню.
- **Питание** – «Завершить работу» или «Перезагрузка» с подтверждением.
- **лог** – выбор и просмотр последних записей логов.
- **Справка** – снова откроет эту инструкцию.
- **Настройки** – откроет раздел управления параметрами бота.

- **Особые функции** – раздел для работы с микрофоном, звуковыми и видеофайлами:
  - **Синтез речи** — генерация аудио по тексту через Google TTS или офлайн-движок pyttsx3.
  - **Отправить голос** — режим ожидания голосовых сообщений и сохранения их в формате .wav.
  - **Очистить sound / videos** — удаляет файлы из соответствующих папок.
  - **Громкость** — управление громкостью системы (повышение, понижение, включение/отключение).
  - **Снимок с камеры** — делает фотографию с выбранной веб-камеры.
  - **Видео с камеры** — запись видео с камеры с возможностью включения timelife-режима (короткие сегменты).
  - **Воспроизведение на компьютере** — проигрывание последнего аудиофайла через системный звук.  - **Запись с экрана** — запись экрана в файл (при возможности — с системным звуком).

## Описание встроенного локального сервера


**Автонастройка локального API**

При первом запуске EXE-файла локальный Telegram Bot API автоматически распакуется в папку `serverapibot`.
Для начальной настройки достаточно ввести данные **API ID**, **API Hash** и **Port**, нажать **«Старт»** — и сервер поднимется автоматически.
В приложении предусмотрён встроенный графический интерфейс для запуска и управления локальным Telegram Bot API-сервером.

### Основные поля:
- **API ID** — ваш числовой идентификатор из Telegram (вводите свой, а не чужой).
- **API Hash** — секретная строка из Telegram (храните в тайне).
- **Local Mode** — включение/отключение локального режима работы.
- **Listen IP** — IP-адрес, на котором сервер будет слушать запросы (например, `0.0.0.0` или `127.0.0.1`).
- **Port** — порт для подключения (например, `8081`).
- **Max Webhook Connections** — максимальное число одновременных webhook-подключений.
- **Уровень логирования** — степень детализации логов (0–5).
- **Макс. размер UI-логов (МБ)** — ограничение на объём логов интерфейса.
- **Data Dir** — папка для хранения данных сервера.
- **Temp Dir** — временная папка для промежуточных файлов.
- **Server EXE** — путь к исполняемому файлу `telegram-bot-api.exe`.
- **Автостарт при запуске** — запускать сервер вместе с приложением.

### Кнопки управления:
- **Старт** — запустить сервер.
- **Стоп** — остановить сервер.
- **Сохранить** — сохранить все указанные параметры.

### Панель логов:
- **UI Логи** (слева) — события интерфейса.
- **API Логи** (справа) — внутренние сообщения сервера с метками времени.

### Строка состояния:
- Показывает текущий статус сервера: «Запущен» или «Остановлен».

## Работа через Telegram API: стандартный vs локальный сервер

Программа поддерживает подключение как к **стандартному Telegram API серверу**, так и к **локальному API серверу**, например, через `telegram-bot-api` (https://github.com/tdlib/telegram-bot-api).
можно использовать встроенный сервер
### Отличия:

| Тип сервера           | Максимальный размер файла | Преимущества                                       |
|-----------------------|---------------------------|----------------------------------------------------|
| Стандартный Telegram  | **~50 МБ**                | Простая настройка, не требует отдельного запуска   |
| Локальный API сервер  | **до 2 ГБ**               | Увеличенные лимиты на видео/файлы, приватность     |

### Особенности при работе с файлами и видео:
- При стандартном Telegram API все голосовые, аудио и видеофайлы **не должны превышать ~50 МБ**.
- При использовании локального сервера можно загружать **видео до 2 ГБ**, и **голосовые сообщения** напрямую копируются с сервера (без скачивания).
- Некоторые функции, например, **разбиение видео на части**, автоматически активируются при превышении лимита.

### Как использовать локальный сервер:
1. Установите и запустите `telegram-bot-api` на своей машине или сервере.
2. В графическом интерфейсе бота укажите:
   - `Адрес API` — например, `http://127.0.0.1`
   - `Порт API` — например, `8081`
3. Запустите бота с этими настройками — файлы будут обрабатываться локально, и ограничения Telegram снимаются.


## Настройки внутри бота
- **Авторизация**
  - Изменить/Удалить PIN-код.
  - Добавить/Удалить ID аккаунтов.
  - Экспорт данных входа (token, pin, allowed_ids).
  - Сменить токен (бот перезапустится автоматически).
- **Система**
  - Проверка системы: версия базового Python и список пакетов.
  - Проверка целостности: наличие `Python.zip` и папки `python`.
  - Переустановить Python (распаковать ZIP заново).
  - Очистить Python (удалить все пакеты, кроме pip/setuptools/wheel).
  - Полный перезапуск бота.
- **Память**
  - Информация о потреблении RAM ботом и системой.
- **Сброс**
  - Полный сброс директории (кроме `config.ini`, `python.zip`, EXE).
  - Выборочное удаление элементов.
- **Резервное копирование и восстановление**
  - Создать/Восстановить полную резервную копию (`full_backups/`).
  - Удаление всех или частичное удаление архивов.
